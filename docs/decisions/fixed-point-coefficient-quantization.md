# 고정소수점 Biquad 계수 양자화

## Decisions

- Biquad 계수를 정수 Q-Format으로 양자화할 때, b0/b1/b2는 사용자가 선택한 Q-Format(Q15/Q23/Q31) 그대로 양자화한다.
- a1/a2(피드백 계수)는 같은 전체 비트 폭을 유지하되, 정수부에 2비트 여유를 더 둔 포맷(예: Q15 선택 시 a1/a2는 Q13)으로 따로 양자화한다.
- 생성된 C 코드는 b 계수용 시프트 상수(`LPF_Q_SHIFT`)와 a 계수용 시프트 상수(`LPF_A_SHIFT`)를 분리해서 내보낸다. 곱셈 후에는 각 계수 자신의 fractional bit 수만큼 오른쪽으로 시프트해 원래 신호 스케일로 되돌린다.

## Boundaries

- 이 규칙은 `lib/codegen-fixed.ts`의 정수 C 코드 생성에만 적용된다. 시뮬레이션용 float 계산이나 `lib/codegen.ts`(float C 코드 생성)에는 적용되지 않는다.
- 2비트 여유는 안정한 2차 Biquad 섹션에서 이론상 |a1|<2, |a2|<1이라는 사실에 기반한다. 필터 설계 방식이 바뀌어도(Chebyshev/Elliptic 추가 시) 이 상한은 유지되므로 그대로 적용 가능하다.

## Why

Butterworth를 포함한 일반적인 2차 Biquad 저역통과 섹션은 a1이 절댓값 1을 넘는 경우가 흔하다(예: Fs=48000, Fc=1000일 때 a1≈-1.815). b/a 계수를 모두 같은 Q-Format(예: Q15, 범위 -1~0.99997)으로 양자화하면 이 값이 saturate되어 -32768(= -1.0)로 깎여버리고, 실제와 다른 잘못된 필터가 생성된다. a1/a2에만 정수부 여유를 더 둔 포맷을 쓰면 이 문제를 해결하면서도 b 계수의 정밀도는 그대로 유지할 수 있다.

## Reconsider when

- 고차 cascade나 다른 필터 설계 방식에서 |a1| 또는 |a2|가 2비트 여유(최대 ±4)로도 부족한 경우가 실측으로 확인되면, 여유 비트 수를 늘리거나 섹션별 동적 스케일링으로 재검토한다.
