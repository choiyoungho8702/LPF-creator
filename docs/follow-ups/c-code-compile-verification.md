# C 코드 생성 결과물의 실제 컴파일 검증 부재

**증상**: `lib/codegen.ts`가 생성하는 C 코드(`generateFloatBiquadCCode`)는 문자열 템플릿 테스트로만 검증되어 있고, 실제 C 컴파일러로 컴파일 가능한지 확인되지 않았다.

**근거**: 이 개발 환경에는 gcc/cc/clang이 설치되어 있지 않다(`which gcc/cc/clang` 모두 실패). 표준 C 문법만 사용했다고 판단해 작성했지만, 실제 컴파일 검증은 수행하지 못했다.

**시도한 것**: 시스템에서 사용 가능한 C 컴파일러를 찾아봤으나 없었다.

**제안하는 다음 단계**: C 컴파일러가 있는 환경(CI 또는 로컬)에서 생성된 코드 샘플을 실제로 컴파일해 문법 오류가 없는지 확인한다. 가능하면 테스트 스위트에 "생성된 C 코드가 컴파일된다"는 체크를 추가한다(예: Node에서 임시 .c 파일로 저장 후 gcc -c 실행).
