# FLAC 실제 오디오 디코딩 미구현

**증상**: `lib/flac.ts`의 `parseFlacHeader`는 FLAC STREAMINFO 메타데이터(Fs/비트 뎁스/채널 수)만 읽고, 실제 압축된 오디오 프레임을 디코딩하지 못한다. UI(`app/page.tsx`)도 `.flac` 업로드 시 "아직 지원하지 않는다"는 에러만 보여주고 처리하지 않는다.

**근거**: FLAC는 단순 헤더 파싱과 달리 서브프레임 예측/엔트로피 코딩을 포함한 실제 압축 해제 로직이 필요해, 직접 구현하거나 라이브러리를 도입해야 한다.

**시도한 것**: 이번 작업에서는 범위를 wav(완전 지원) + flac(헤더만) + raw/pcm(완전 지원)으로 좁혀서 진행했다.

**제안하는 다음 단계**: FLAC 디코딩이 실제로 필요해지면, 순수 JS/WASM FLAC 디코더 라이브러리 도입을 검토하거나, 브라우저의 `AudioContext.decodeAudioData`로 디코딩한 뒤 우리 파이프라인(`decodePcmSamples` 포맷)에 맞게 변환하는 방법을 조사한다.
